# 식품접객업소 식품안심업소(위생등급) 지정 현황 조회 서비스

식품의약품안전처 **식품안전나라 공공데이터(C004 Open API)**를 활용하여 사용자의 **접속 지역(현재 위치) 기반 위생등급 지정 식품안심업소 목록을 조회 및 시각화**하는 풀스택 웹 애플리케이션입니다.

---

## 🛠️ 기술 스택

- **백엔드 (Backend)**
  - **Framework**: FastAPI (Python 3.10+)
  - **Server**: Uvicorn
  - **HTTP Client**: HTTPX (비동기 통신)
  - **API 연동**: 식품의약품안전처 식품안전나라 Open API (`C004`)
  - **위치 감지**: IP 기반 위치 감지 (`ip-api`) 및 GPS 좌표 역지오코딩 (`Nominatim OSM`)

- **프론트엔드 (Frontend)**
  - **Framework**: React 19 + Vite (Multi-page App)
  - **Map Engine**: Leaflet (OpenStreetMap) 기반 지도 렌더링
  - **Pages**:
    - `index.html` (메인): 접속 지역 안심식당들의 주소를 지오코딩하여 **지도 위에 마커 핀으로 표시**
    - `list.html` (목록): 안심식당 **상세 카드/표 목록 및 필터 검색**
  - **Icons**: Lucide React
  - **HTTP Client**: Axios

## 📋 식품안전나라(C004) API 필드 매핑

사용자 요구 명세에 맞춰 아래 주요 4개 필드를 포함하여 데이터를 조회 및 출력합니다:

| 요구 항목 | 식품안전나라 필드명 | 설명 | 출력 형태 |
|:---|:---|:---|:---|
| **지정등급** | `HG_ASGN_LV` | 위생등급 지정 등급 (적합, 매우우수, 우수, 좋음 등) | 등급별 컬러 배지 표시 |
| **업소명** | `BSSH_NM` | 식품접객업소 상호명 | 볼드 텍스트 및 업종 태그 |
| **주소** | `ADDR` | 소재지 도로명/지번 주소 | 주소 복사 & 카카오맵 바로가기 |
| **영업상태** | `CLSBIZ_DVS_CD_NM` | 정상, 폐업 등 영업 구분 | 상태별 배지 (정상/폐업) |

*추가 제공 필드:*
- `INDUTY_NM`: 업종 구분 (일반음식점, 휴게음식점, 제과점 등)
- `TELNO`: 전화번호
- `ASGN_FROM` ~ `ASGN_TO`: 위생등급 지정 유효기간
- `INSTT_CD_NM`: 관할 지자체/기관

## 🔑 환경 변수 (.env) 설정

프로젝트 루트 또는 `backend/` 디렉터리의 `.env` 파일에 발급받은 식품안전나라 API 인증키를 설정할 수 있습니다:

```env
# 식품의약품안전처 식품안전나라 Open API 인증키
# (공공데이터포털 또는 foodsafetykorea.go.kr에서 발급)
FOOD_SAFETY_API_KEY=sample
```
* 미입력 또는 미설정 시 기본 공공 테스트용 키(`sample`)가 자동으로 사용됩니다.
* 보안을 위해 `.env` 파일은 `.gitignore`에 등록되어 있습니다.

## 🚀 빠른 시작 (실행 방법)

### 1. 백엔드 (FastAPI) 실행
```bash
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
- 서버 주소: `http://localhost:8000`
- API 문서(Swagger UI): `http://localhost:8000/docs`

### 2. 프론트엔드 (React + Vite) 실행
```bash
cd frontend
npm install
npm run dev
```
- 프론트엔드 접속 주소: `http://localhost:5173`

## ✨ 주요 기능

1. **접속 지역 자동 감지**
   - 브라우저 접속 시 HTML5 Geolocation API(GPS) 및 IP 기반 위치 감지를 통해 사용자의 접속 지역(예: `대구광역시 수성구`, `서울특별시 강남구` 등)을 자동 감지합니다.
   - 상단 헤더에 `📍 접속 지역: [지역명]` 배지가 표시되며, 해당 접속 지역의 식품안심업소 목록을 즉시 불러옵니다.
   - 언제든 **[현재 위치로 재탐색]** 버튼을 눌러 GPS 좌표를 새로고침할 수 있습니다.

2. **전국 지역 탐색 & 필터링**
   - 대한민국 17개 시/도 및 하위 시/군/구 드롭다운 셀렉터를 제공하여 원하는 다른 지역의 업소도 간편하게 조회할 수 있습니다.
   - 업소명 검색 기능(엔터 또는 검색 버튼)을 제공합니다.
   - 영업상태 필터: `정상`, `전체`, `폐업`
   - 지정등급 필터: `전체`, `적합`, `매우우수`, `우수`, `좋음`

3. **다양한 뷰 모드 & 편의 기능**
   - **카드 뷰**: 업소별 핵심 정보, 등급 뱃지, 유효기간, 주소 복사, 카카오맵 길찾기 링크 제공
   - **표(Table) 뷰**: 대량의 목록을 한눈에 확인할 수 있는 테이블 형태 제공
   - **페이지네이션**: 대용량 데이터를 페이지 단위로 깔끔하게 탐색
   - **API 키 관리 모달**: 기본 내장 샘플 키(`sample`) 외에 사용자의 식품안전나라 개인 인증키 등록 지원 (LocalStorage 저장)
